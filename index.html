Atalhos Práticos:

1. Sistemas Operacionais

  • Desktop vs Servidor: Servidor foca em CLI, processos em background, alta disponibilidade (uptime) e sem GUI pesada.
  • Linux: Rei da Nuvem e Web. Licença GPL. Distribuições: RHEL/Rocky, Ubuntu Server.
  • BSD: FreeBSD (ZFS, alta performance de rede), OpenBSD (Foco total em segurança padrão). Licença BSD permissiva.
  • Windows Server: Soberano em Redes Internas. Usa GUI + PowerShell. Destaque para o Active Directory (AD DS) e IIS.

2. Virtualização & Containers

  • Hypervisors (VMs): Tipo 1 (Bare Metal - VMware ESXi, Proxmox, KVM, Hyper-V) vs Tipo 2 (Hosted - VirtualBox).
  • VM vs Container: Máquinas Virtuais emulam todo o SO + Kernel (pesadas). Containers compartilham o Kernel do hospedeiro (leves).
  • Docker vs LXC: Docker é voltado a aplicação isolada/microsserviços. LXC cria containers de sistema (estilo VM leve).
  • Kubernetes (K8s): Orquestrador para gerenciar múltiplos containers em escala.

3. Servidores Web

  • Apache: Baseado em processos/threads. Suporta configurações descentralizadas (.htaccess).
  • Nginx: Orientado a Eventos (assíncrono). Resolve o problema C10k com consumo mínimo de RAM. Excelente Proxy Reverso.
  • IIS: Servidor web nativo do Windows Server. Integração nativa com .NET, web.config e Active Directory.
  • Proxy Reverso: Esconde os servidores backend, faz balanceamento de carga (Load Balancer) e terminação SSL/TLS.

4. Hospedagem na Nuvem

  • CAPEX vs OPEX: CAPEX = Investimento inicial em hardware (On-premises). OPEX = Despesa operacional sob demanda (Cloud).
  • Pirâmide As-a-Service:
    - IaaS: Infraestrutura pura (ex: AWS EC2, Azure VM).
    - PaaS: Plataforma pronta para subir código (ex: Elastic Beanstalk).
    - SaaS: Software pronto para uso (ex: Google Workspace, Office 365).
  • Elasticidade / Auto-Scaling: Aumenta/diminui instâncias automaticamente conforme demanda.

5. Segurança, Logs e IAM

Camadas de Defesa

Firewall L3/L4: Filtra apenas por IP de origem/destino e Porta de rede.

WAF (L7): Analisa o payload HTTP. Bloqueia ataques web como SQL Injection e XSS.

IDS vs IPS: IDS é passivo (escuta e gera alertas/câmera). IPS é ativo (intercepta e bloqueia pacotes/segurança na porta).

IAM & Auditoria

IAM (Identidades): AD/LDAP/RADIUS centralizam login em múltiplos servidores, evitando criar contas locais em cada máquina.

Syslog: Protocolo padrão de coleta e centralização de logs do sistema.

SIEM: Plataforma que correlaciona logs de múltiplos servidores em busca de ameaças ativas.
